# Omarchy Theme and Background Actions

A top-bar widget for Omarchy with actions to:

- Add a background
- Remove a background
- Choose a background
- Choose a theme
- Remove a theme

## Install

```bash
./install.sh
omarchy restart shell
```

The widget appears as **Theme Picker** in the top bar. Left-click opens the
action menu. Right-click opens the theme switcher directly.

## Remove

```bash
omarchy plugin remove local.theme-picker
```
